# AI-slop checklist

Scan the rendered result against this list and fix what you find. Each item is a default, not a choice; the brief's own words still win when it asks for one of them.

## Color and surface
- Purple or purple-blue gradients; gradient buttons.
- Multi-layer shadows; semi-transparent stacked colors.
- A card inside a card; dividers and bordered containers used everywhere.
- A colored vertical stripe on the left edge of a card.
- Colorful square icon tiles; a different color per card.

## Type and labels
- Instrument Serif, Space Grotesk or Bricolage Grotesque by reflex; monospace used as decoration.
- ALL-CAPS small headings, an eyebrow label above a heading, code-style breadcrumbs, chapter numbers on non-sequences.
- More than 4 type sizes, or any below 12px.
- Middle-dot separators ("A · B · C"), emoji in body text, tags and italics everywhere.
- Explanatory text that explains nothing.

## Hero and layout
- A small capsule badge, a centered oversized headline, and one emphasized word.
- Abnormally large hero type.
- Excessive scroll choreography; abrupt transitions.
- Charts with too much fine detail.

## Geometry
- Nested radii that are not concentric; mixed line thicknesses.

## Assets
- Another brand's imagery reused as your own.

## Sensible exceptions
- Monospace for real code or tabular data, ALL-CAPS for an established abbreviation, numbering for a true sequence, a left stripe that encodes a status in a data table. Keep one only when it carries information.
