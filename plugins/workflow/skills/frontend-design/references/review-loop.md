# Review loop

1. Build the whole thing with the SKILL.md plan and the token floor in hand.
2. Take screenshots at several widths (mobile, tablet, desktop; plus dark if supported). Score them against `slop-checklist.md` and `tokens.md`.
3. Rank problems by severity. Fix one place per pass; repeat 2-4 passes. Fixing everything at once makes regressions hard to see.
4. List the changes as "element: old -> new" (radius, size, color, spacing) so the user can audit them.
5. Final look is the human's. Ship, watch reactions, then polish.

Without a browser, review the CSS and markup against the same two files and say that no render was checked.
