# Manual Git profile

Do not stage, commit, push, merge locally, create/send tags, create/update PRs, or perform GitHub writes merely to finish an implementation task. Run only the Git/GitHub operations explicitly requested by the user, within that request's scope. A prior implementation approval is not a Git write request. Existing main/master, force, destructive-operation, release and remote-deletion gates remain in force. Permission prompts are additional enforcement, not authorization to expand scope. Unknown wrappers grant no permission.
