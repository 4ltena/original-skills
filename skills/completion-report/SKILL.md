# Completion report

Check the requested outcome against observed evidence. Report concisely in the user's language: result, relevant changed paths, actual verification and material remaining work. Never turn unrun checks, worker claims or installed files into proof of runtime behavior.

Use a short paragraph for a small change and a list only when several results need separation. Include launch instructions or a next action only when needed. Project continuity belongs to project-handoff when available and applicable; reporting alone does not require repository rediscovery, persistence, versioning or publication.
